# 09 — Repo này

Ghi chú chỉ đúng với repo `platform`. Phần này sẽ lỗi thời khi refactor — cứ
sửa thoải mái, đừng tiếc.

Phần "cách dùng" (script, lệnh chạy) nằm ở [README.md](../../README.md) gốc.
Ở đây là phần **vì sao**.

## Mục lục

| File                         | Nội dung                                  |
| ---------------------------- | ----------------------------------------- |
| [decisions.md](decisions.md) | Các quyết định kỹ thuật và lý do đằng sau |
| _troubleshooting.md_         | _(chưa viết)_ lỗi đã gặp và cách gỡ       |

## Nên ghi gì vào đây

- Mỗi lần mất hơn 30 phút để gỡ một lỗi → viết vào `troubleshooting.md`:
  thông báo lỗi nguyên văn, nguyên nhân thật, cách sửa. Nguyên văn quan trọng vì
  lần sau bạn sẽ tìm bằng cách paste lại thông báo lỗi.
- Mỗi lần chọn A thay vì B → thêm mục vào `decisions.md`.
- Đừng chép lại thứ mà code đã nói rõ. Ghi cái mà đọc code không thấy được:
  lý do, các phương án đã loại, ràng buộc bên ngoài.
